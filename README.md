# Nisha Gallery

Original artworks, each sold as a **normal copy** (signed print + high-res download) and a **1-of-1 NFT copy** on Polygon.
Pay by UPI, card or netbanking (Razorpay), or with Polygon, Ethereum, BNB, Bitcoin or Solana.

- Site: https://sanjaydoc.github.io/nisha-gallery/
- Admin: https://sanjaydoc.github.io/nisha-gallery/#/admin (gallery admin Google account only)

Develop: `npm install`, `npm run dev`. Release: `npm run build`, commit `docs/`, push `main`.
The API lives in MedDroid's chat Worker (`/gallery/*`); see `CLAUDE.md`.
